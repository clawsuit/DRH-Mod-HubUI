# Mod Hub

One panel for the settings and windows of the mods that support it.

> **Requires Mod Hub API.** Enable **Mod Hub API** (`mod_hub_api`) together with this mod. The API
> holds the list of mods; this panel is what shows it.

<!-- drh:show -->
## Open it

Press **F1**, or click the **module button** that appears in town above the game's options gear.

The button only appears in town.

## What you can do

- See the mods that have registered with the hub, with their description and current state.
- **OPTIONS** opens the settings a mod offers.
- **OPEN** opens the mod's own window; when you close it, the hub comes back.
- **BACK** returns from a mod's settings to the list.
- **F1** or **ESC** closes the hub. In settings, **ESC** goes back to the list.
- The **EN/ES** button switches the hub and the mod options between English and Spanish.

## Change the hub key

1. Open the hub.
2. Open **Mod Hub → OPTIONS → Hub key**.
3. Click the key button and press the key you want.
4. **ESC** cancels. Letters, numbers, the numpad and **F1–F12** are accepted.

The new key is saved and used immediately. If a key is already used by the game or another mod,
choose a different one.

## Notes

- Some mods only have settings; others also have their own window.
- If no mods are listed, make sure the mods you want are enabled and that **Mod Hub API** is enabled
  too.
